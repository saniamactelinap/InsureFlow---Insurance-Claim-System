Tier 4: Data Persistence & Resilient Storage Architecture (Mongoose ODM & MongoDB)
Primary Production Database: MongoDB Atlas
• Cloud-Hosted High-Availability Replica Set (Shared Cluster on AWS/GCP)
• Enforces Document Validation, Unique Indexes, and Foreign Key References (ObjectId)
• 14 Specialized Collections: Users, PolicyProducts, CustomerPolicies, Claims, ClaimDocuments, OCRJobs, ConfigurableRules, SurveyAssignments, SurveyReports, Settlements, ClaimTimelineEvents, Notifications, AuditLogs, PolicyApplications.
Automated Fallback: Embedded In-Memory MongoDB Engine
• mongodb-memory-server (v10.1.3) auto-activates if Atlas SSL, IP whitelist, or firewall blocks connection
• Seamless self-healing architecture: starts ephemeral mongod instance on localhost loopback
• Executes automatic baseline database seeder (15 policies, 7 rules, 5 role users, demo policies)
• Powers isolated Jest test suite (14/14 automated unit and integration tests passing).
