1
Claim Filing with PDF Invoice Attachment Customer ➔ API Gateway
Customer inputs incident details, selects active policy (customerPolicyId), attaches medical bill/repair estimate, and triggers POST /api/claims with JWT Bearer Token.
2
Multipart Stream Ingestion & Claim Entity Creation API Gateway ➔ MongoDB
Multer streams file into server/uploads/ with randomized UUID filename. Express initializes new Claim entity with status SUBMITTED and reference CLM-YYYYMMDD-XXXX.
3
Asynchronous OCR Text & Field Extraction API Gateway ➔ OCR Service
OCR service evaluates MIME type. Extracts selectable text via pdf-parse or renders page streams to tesseract.js optical worker. Extracts regex fields (Invoice No, Dates, Total Amount) and computes composite confidence score.
4
Deterministic Claim Rule Engine Execution API Gateway ➔ Rule Engine Service
Executes evaluateClaim(claimId) against active policy. Assesses: 1) Active Date Coverage, 2) Category Match, 3) Coverage Limit Compliance, 4) Document Completeness, 5) Duplicate Submission Check, 6) Policy Source Authentication, 7) High-Value Surveyor Trigger.
5
Persist Automated Validation & Log Timeline Event Rule Engine ➔ MongoDB & FSM
Claim document updated with automatedValidation (status: PASS/FLAGGED/REQUIRES_REVIEW/FAIL, score: 0-100%). FSM records immutable ClaimTimelineEvent in MongoDB.
6
Officer Queue Fetch & OCR Cross-Audit Officer ➔ API Gateway ➔ MongoDB
Officer opens /officer/claims/:id. System renders side-by-side OCR audit modal comparing extracted PDF amounts against claimed amounts. Officer audits rule compliance badges.
7
Officer Recommendation & Manager Escalation Officer ➔ API Gateway ➔ FSM
Officer approves audit, inputs recommendation note and recommended amount, executing POST /api/claims/:id/recommend. FSM transitions claim to MANAGER_REVIEW.
8
Manager Final Adjudication & Settlement Generation Manager ➔ API Gateway ➔ Settlement Service
Manager reviews officer notes and rule score. Executes POST /api/manager/claims/:id/approve. FSM updates claim to SETTLEMENT_PENDING and instantiates Settlement record (SET-YYYYMMDD-XXXX).
9
Settlement Execution & Customer Notification Settlement Service ➔ MongoDB ➔ Customer
Finance marks settlement SETTLED with bank transaction reference. Notification service pushes in-app alert to customer. Customer views settled status and payment reference in /customer/settlements.
